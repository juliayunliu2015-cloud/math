02

Right triangles

For legs a and b, and hypotenuse c (opposite the right angle):

a2 + b2 = c2

Common Pythagorean triples. Each scaled set keeps the same right-triangle shape.

  • 3 - 4 - 5also 6-8-10, 9-12-15, 12-16-20

05

Fast multiplication by 25 & 125

For 25: turn it into 100, then divide by 4.

25 x n = (100 x n) / 4

For 125: turn it into 1000, then divide by 8.

125 x n = (1000 x n) / 8
25 x 4 = 100
25 x 8 = 200
25 x 12 = 300
125 x 4 = 500
125 x 8 = 1000
125 x 16 = 2000
